# Code of conduct

Be kind and be exact.

- Talk about the code and the reasons, not about the person.
- Say what you saw, what you expected, and how to see it again.
- No harassment, no insults, no personal attacks, in any language.

A maintainer may edit or remove what breaks this, and may block someone who keeps doing it.
To report a problem in private, use **Security → Report a vulnerability** on this repository
and say it is a conduct report.
